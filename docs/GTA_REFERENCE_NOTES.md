## 适合当前工程的实现矩阵

当前工程为约 500 米街区、程序生成场景和角色的 UE 原型。先完成一段能反复游玩的循环，再扩大内容；不要仅增加对象数量掩盖操作和性能问题。

| 顺序 | 内容 | Neon Coast 可落地版本 | 验收要点 | 参考性质 |
|---|---|---|---|---|
| P0 | 驾驶与镜头 | 帧率独立运动、平滑转向、碰撞后减速、车轮转动、跟车镜头稳定 | 30 / 60 / 144 FPS 路程接近；平路高度稳定；连续转弯与撞墙可恢复 | 用户明确痛点；非 GTA VI 物理复刻 |
| P0 | 上下车与高速跳车 | 安全出口查询、角色速度继承、短暂恢复、车辆继续滑行 | 静止 / 高速 / 侧门受阻 / 全出口受阻都可预测；重新跳跃正常 | 用户明确痛点 |
| P0 | 活的街区 | 可见行人、步行路线、问候、车辆靠近受惊；路口转弯和前车避障 | 出生位置立即能看到 NPC；行人确实移动；车流不持续堆堵 | 原创沙盒系统 |
| P1 | 完整任务链 | 迁移旧版四段原创任务：取送物品、下车取件并逃脱、检查点竞速、最后交付；有开始、失败重试、奖励和结局 | 奖励只发一次；交付要求人在车内并减速；竞速不能步行作弊；失败能重新开始 | 原创故事，借鉴开放世界犯罪冒险类型 |
| P1 | 通缉和逃脱 | 犯罪事件提高热度；警车追逐；脱离视线进入搜索；躲藏一段时间解除 | 追逐能看见、可逃脱；遮挡有作用；没有永远粘住玩家的警车 | 原创规则；不宣称复制 GTA VI 警方识别机制 |
| P1 | 枪械与伤害 | 瞄准、射击、弹药 / 换弹、命中反馈；NPC 逃跑；伤害和重生接入任务 | 不穿墙命中；碰撞和死亡状态一致；输入不会与驾驶冲突 | 旧版已有，可移植验证 |
| P1 | 存档与进度 | 任务、现金、收集物、玩家位置、设置；任务中断后安全恢复 | 重启后恢复；损坏存档有备份；测试不覆盖玩家存档 | 完成产品所需 |
| P1 | 导航与菜单 | 真实小地图、目标距离、地图标记、暂停、键鼠及手柄提示 | 标记与世界坐标一致；暂停后输入不残留；菜单可返回 | 完成产品所需；视觉交给 Opus |
| P2 | 昼夜与环境声 | 连续光照过渡、夜间车灯 / 招牌、海浪 / 城市底噪、引擎和鸣笛 | 过渡不突变；夜间能看清路；音量设置有效 | 原创氛围设计 |
| P2 | 车载电台 | 少量原创合成音乐频道，切换 / 关闭，进出车切换混音 | 真正可听；不会多路重叠；不使用 Rockstar 曲目 | 电台概念由官方确认；内容原创 |
| P2 | 探索支线 | 明信片收集、维修点、路边事件、可重玩的竞速 | 奖励和存档可靠；所有点位可达；有清晰交互提示 | 旧版系统扩展 |
| P2 | 伙伴 | 独立原创伙伴随行，靠近玩家并在任务中提供短提示；成熟后再评估双角色切换 | 不阻挡玩家、不瞬移到视野中心、不破坏上下车 | 双主角故事是官方信息；本方案为原创适配 |
| P3 | 更大世界与交通工具 | 独立海湾 / 工业区、可驾驶小艇、更多室内点位 | 各区域有实际玩法且性能可接受后才扩张 | 地区多样性启发；不推断原作地图规模 |

## 范围与依赖

- 城市、HUD、角色 / 车辆外观的美术改进继续交由 Claude Opus 5.5；整合时记录模型回执与文件变化。
- 原创地名、人物、任务、招牌与音乐，不搬运 Rockstar 模型、贴图、配乐、对白或原作地图。
- UE 5.8 的渲染能力不自动带来 RAGE 的资产规模、行为系统和长期打磨。实现状态以本工程的编译、行为测试、实际渲染与独立 EXE 结果为准。
- 不把“所有建筑都可进入”“海量永久 NPC 记忆”“固定车辆 / 动物数量”“完整社会模拟”“特定通缉星数或证据识别规则”等未经本次官方资料直接核实的说法列为 GTA VI 事实。
- 旧版操作和四段任务规格见 [CONTROLS.md](CONTROLS.md)。旧版 Godot 测试只能作为移植参考，不能替代 UE 的验收。
