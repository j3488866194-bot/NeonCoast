# v0.4.1 启动菜单、声音与新手引导

双击桌面 Neon Coast 或发行包根目录 `NeonCoast.exe`，进入霓虹海岸主菜单。可开始/继续游戏、打开设置、查看操作指南或确认退出。游戏中按 Esc / 手柄 Menu 暂停；返回主菜单会保留当前会话，继续游戏不会清空进度。

## 首次游玩

第一次开始游戏会出现欢迎页，随后按真实操作依次练习视角、步行、上车、驾驶后停稳和下车。操作提示显示在画面角落；暂停、地图和照片模式中不累计练习进度。完成后会介绍快递互动和地图入口。

按 F2 可跳过，也可在欢迎页选择跳过。完成或跳过会记住，下次不再自动出现；操作指南中的“重新体验新手引导”可随时重看。重看不会清除任务或现金。

## 启动与声音

默认每次启动采用显示器原生尺寸的无边框模式。设置 → 画面可关闭“启动时自动无边框”，随后保留所选窗口模式；本次游戏仍可手动切换显示方式。未确认显示变更的安全恢复优先。

主菜单和暂停菜单现在有独立音乐与海岸环境声；游戏中保留车辆、电台、脚步和其他音效。设置 → 声音的“试听当前音量”使用已应用的音效音量，更改音量后先按应用。总音量或音效为零时试听也保持静音。声音跟随 Windows 默认输出设备；若系统选中显示器，声音将送往该显示器的音频接口。

## 视角方向

默认鼠标上移、手柄右摇杆上推均向上看，步行和驾驶使用同一套规则。设置 → 操控允许分别反转鼠标/手柄的 Y 轴，调整各自灵敏度及摇杆死区。应用后保存到本机用户配置，重启后继续使用。

旧实现中 UE 的 `Gamepad_RightY` 预处理、项目轴映射、旧版 `InputPitchScale=-2.5` 叠加，导致上下方向颠倒。本版关闭旧版隐含缩放，在映射中补偿引擎输入符号，并分别处理鼠标和手柄。右摇杆死区只应用一次，驾驶不再重复经过鼠标灵敏度。

## 设置行为

- 画面：窗口/无边框/全屏、启动时自动无边框、分辨率、画质、帧率上限与垂直同步。
- 操控：鼠标与手柄灵敏度、各自 Y 轴反转、手柄死区。
- 声音：总音量、音乐、音效和音量试听。总音量为零时完全静音。
- 修改先进入草稿，按“应用”才生效并保存。返回会丢弃未应用的修改；恢复默认也先进入草稿。
- 改变分辨率或窗口模式后需在 15 秒内确认保留，否则恢复之前的显示模式。确认过程中异常退出，下次启动也会恢复已确认值。
- 初次升级迁移旧版显示配置，已有本版配置优先；游戏进度与设置分别保存。

打开菜单会暂停世界，并释放持续开火、瞄准、冲刺、跳跃及车辆油门/刹车输入。退出时若进度保存失败，会留在菜单显示失败原因。

## 开发验证

菜单及输入检查使用真实 Slate 按键事件和 UE 场景视口模拟摇杆轴，验证步行与驾驶相机方向；这不替代物理手柄硬件验收。原有玩法/警方检查使用 `-NeonCoastSmokeTest` / `-NeonCoastPoliceTest` 自动跳过启动菜单。游戏画面采样使用 `-SkipFrontEnd`。

设置自动化覆盖方向、独立配置往返、无效值、未确认显示恢复、旧配置迁移、启动无边框和引导记忆。声音验证采集本游戏的实际主混音 PCM，分别测量菜单、步行、车辆、电台、试听与静音。它不代表已验证物理扬声器的可听性。完整发行验证与文件哈希见 [UE_VERIFICATION.md](UE_VERIFICATION.md)。

菜单视觉由实际 Claude Opus 5.5 high 编写；控制器接入、输入/配置后端、编译修正和验证由 Codex 完成。作者调用回执与最终验证是不同证据。
