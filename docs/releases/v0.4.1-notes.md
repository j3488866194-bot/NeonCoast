# Neon Coast v0.4.1

修复打开菜单后音乐与环境声随世界暂停的问题，增加菜单专用声音，并提升游戏中偏轻的环境与车辆混音。设置 → 声音可试听已应用的音效音量；静音设置仍完全有效。

游戏默认随启动进入桌面尺寸的无边框模式，旧版配置升级后也会生效。可在画面设置关闭“启动时自动无边框”，保持自己的显示偏好；异常显示设置仍优先恢复。

首次开始游戏增加中文操作引导，依次练习视角、步行、上车、驾驶停稳和下车。完成或跳过后不再自动出现，可在操作指南中重看；F2 随时跳过。引导界面继续由实际 Claude Opus 5.5 high 制作。

安装更新会保留已有游戏进度与用户文件。便携版请完整解压到新目录，并复制旧目录中的 `NeonCoast/Saved` 以保留进度。

声音跟随 Windows 默认输出设备；游戏主混音验证与物理扬声器可听性是不同范围。详细检查、截图和文件绑定见仓库发行验证记录。

已知问题：本机安装版启动检查中出现过一次 DX12 显卡超时（DXGI_ERROR_DEVICE_HUNG）。相同启动方式重试的 18 项检查和随后两分钟正常运行观察均通过，但根因尚未解决，不能据此保证长时间游玩的稳定性。
