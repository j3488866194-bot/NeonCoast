# NEON COAST · 霓虹海岸

An original coastal open-world action game prototype, built with Godot 4.7.2.

这是一个独立的原创游戏工程，以现代海滨城市、驾驶、行动任务与追捕为主题。它不是 Rockstar 的 GTA VI，不包含官方游戏代码、泄露内容或官方素材。

## Development

Open `project.godot` with Godot 4.7.2. The game is currently being assembled and verified.

Project source, original procedural content, controls and verification scripts are tracked in Git. Engine binaries, export packages, local credentials and generated caches are excluded.
