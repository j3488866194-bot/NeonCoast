# Neon Coast · 操作说明

游戏支持键盘、鼠标和标准手柄输入。下面的手柄名称采用 Xbox 按键布局；连接其他手柄时，以对应位置和游戏提示为准。车速表单位为 **km/h**。

## 基本操作

| 操作 | 键鼠 | 手柄 |
|---|---|---|
| 步行移动 | WASD / 方向键 | 左摇杆 |
| 观察视角 | 鼠标 | 右摇杆 |
| 步行冲刺 | 按住 Shift | 按住左摇杆按钮 |
| 跳跃 | 空格 | A |
| 交互、上下车、任务取件 | F | Y |
| 瞄准 | 按住鼠标右键 | 按住 LT |
| 瞄准时射击 | 鼠标左键 | RT |
| 城市地图 | M | View / Back |
| 暂停 / 返回游戏 | Esc | Menu / Start |
| 菜单选择 | 方向键，Enter 确认 | 左摇杆 / 十字键，A 确认 |
| 切换菜单控件焦点 | Tab / Shift+Tab | RB / LB |

交互会优先处理附近任务，其次处理修理车辆或上下车。靠近车辆后按交互键上车；车辆行驶较快时需要先减速。

地图中点击鼠标可设导航点；也可用方向键 / 左摇杆移动光标，再按 Enter / A 确认。用 Tab / RB 从地图光标切换到“清除自定路线”等按钮，Esc / B 返回游戏。

## 驾驶

| 操作 | 键鼠 | 手柄 |
|---|---|---|
| 加速 | W / ↑ | RT |
| 刹车并倒车 | S / ↓ | LT |
| 转向 | A、D / ←、→ | 左摇杆左右 |
| 手刹 | 空格 | B |
| 加速增强 | 按住 Shift | 按住 A |
| 切换跟车镜头距离 | V | 按右摇杆 |
| 切换电台 / 关闭电台 | R | 十字键 → |
| 鸣笛 | H | LB |
| 开关车灯 | L | 十字键 ↑ |
| 道路救援 | T | 十字键 ↓ |

道路救援会把车辆移回附近道路并修复，扣除最多 $75；通缉期间不可使用。海岸大道青色维修标记处可修理受损车辆，费用 $100，同时恢复生命值。车辆可行驶范围止于海滨道路；下车后可以步行游览栈道和沙滩。

## 四段故事

1. **海风来信**：进入起点旁的 Comet GT，前往金色目标取件，再驾车交付。第一个交付区需要停留约 1.2 秒。
2. **潮汐账本**：到目标处下车取账本，引发追捕；脱离警方视线并等待通缉消失，再驾车前往码头交付。
3. **落日跑线**：驾车在起点按交互键开始，120 秒内依次经过六个检查点。下车不会暂停计时，步行经过检查点不计数；超时后可回起点重试。
4. **最后一程**：驾车在仓库装载货物，摆脱追捕，再驶向棕榈公园停稳交付。

所有交付都要求人在车内，速度低于 9 km/h；完全停车最稳妥。四段故事完成后进入自由漫游。城市中有 10 张海岸明信片，接近即可收集，每张奖励 $150。

## 照片

- **F6**：进入 / 退出照片模式；模式中模拟暂停。
- **WASD / 左摇杆**：移动相机；鼠标 / 右摇杆改变视角。
- **空格 / A**：升高；**Ctrl / B**：降低。
- **Shift / 左摇杆按钮**：加快移动。
- **F12 / 手柄 X**：保存当前画面；**Esc / Menu** 返回游戏。

也可从暂停菜单进入照片模式。照片模式保存时会隐藏界面；照片保存在本机游戏数据目录的 `screenshots` 文件夹中。

## 存档

游戏会在任务完成、收集明信片、暂停或退出等节点保存，并在非通缉状态下定期自动保存。从主菜单继续游戏可以恢复进度。读取进行中的竞速或追捕任务时，会返回该段任务的安全起点，避免读取后直接超时或卡在追捕阶段。

Windows 默认数据目录：`%APPDATA%\Godot\app_userdata\Neon Coast · 霓虹海岸\`。其中 `profile.json` 为进度，`settings.json` 为设置，`.bak` 保存上一版数据。
